- 每个 agent 在 `_index.yml` 中必须提供 id、version、status、scope、mode、consumers、brief、capabilities(supported/pending)、constraints、references、entry.agent-doc 完整字段。
- Agent 契约文档统一使用 YAML front matter 声明 name/description/mode/permission，并在正文中以表格列出责任范围、工作协议步骤、禁止行为与 Skill 映射。
- 通过 constraints 显式列出不可逾越的边界（不得直接写 specs/、不得跳过 review/human_approval、不得修改 _backlog.yml 等），而非隐含约定。
- references 字段只允许引用 `tools/skills/*` 下的 SKILL.md 与少数共享索引（如 reviewer-panel.yaml、specs/_index.yml），禁止引用任意源码文件。
- mode 严格区分为 primary 与 subagent，subagent 仅在 writeback 或质量门等受控阶段由 orchestrator 调用，primary agent 才暴露给 pipeline 或用户入口。
