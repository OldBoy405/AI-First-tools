本模块是纯声明式注册层，不含可执行代码：
- `_index.yml` 为单一事实源，按 `agents[]` 条目登记每个 agent 的 id/name/version/status/scope/mode/consumers/brief/capabilities(pending+supported)/constraints/references/entry.agent-doc。
- 每个 agent 对应一个同名 `.md` 契约文档（如 `dev-agent.md`、`knowledge-agent.md`），使用 YAML front matter 声明 name/description/mode/permission（含 bash: deny 等沙箱权限），正文用表格描述责任范围、工作协议步骤、禁止行为与 Skill 映射表。
- mode 区分 primary（面向用户/pipeline 直接调用）与 subagent（被其他 agent 或 system-orchestrator 编排），consumers 字段明确上游消费者（orchestrator / 各 pipeline / 其他 agent）。
- references 全部指向 `tools/skills/*` 下的 SKILL.md，形成“Agent 契约 → Skill 实现”的单向依赖方向；本模块不引用任何运行时路径，仅做能力清单与准入约束的静态声明。
