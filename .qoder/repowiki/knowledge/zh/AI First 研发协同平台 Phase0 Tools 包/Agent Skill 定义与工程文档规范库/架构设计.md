本模块是纯声明式 Skill 仓库，不含可执行代码（仅 `shared/engineering-docs/scripts/` 保留已弃用的 MCP Server + CLI 历史实现）。核心结构：
- `_index.yml` 为全局 Skill 台账，按 planning / requirement / develop / writeback / sync / competitive / review / spec / cr / shared 十大领域分组登记每个 skill 的 id、path、brief、status，新增 skill 必须在此注册。
- 每个 Skill 位于独立子目录，入口为 `SKILL.md`，通过 YAML frontmatter 声明 name/description/version/consumers/references，正文以步骤化指令描述触发条件、参数表、执行流程、落盘路径与错误处理，由上层 agent 运行时按需加载。
- `reviewer-panel.yaml` 集中配置三张审查面板（review-requirement / review-tech-design / review-code）的 perspective、severity、weight、checklist 及聚合评分公式，作为 review 类 Skill 的统一决策依据。
- `shared/engineering-docs/` 提供跨 Skill 复用的基础设施：templates/ 下 PRD/SDD/MODULE/PLAN/TASK/RELEASE/FORM/OpenAPI 模板；schemas/ 下对应 JSON/YAML Schema 用于 frontmatter 自校验；conventions/ 记录命名与版本规则；standards/ 给出工程结构权威说明。该 Skill 已从 v0.4.0 起去 MCP 化，改为调用方 Agent 直接按步骤渲染模板并写入工作区。
- 依赖方向单向：各业务 Skill → shared/engineering-docs（模板+Schema），Skill 之间不互相引用，仅通过 `_index.yml` 暴露 id 供 pipeline 编排组合（如 `run-competitive-analysis` 委托 fetch-competitor-updates + write-competitive-report）。
