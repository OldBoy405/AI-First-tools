根目录不承载业务逻辑，而是作为「包描述 + 跨子模块契约」的装配层：
- `dir-graph.yaml` 是单一事实源，声明 package、tools.agents/skills/pipeline-templates 三棵子树及其 _index.yml 入口、命名约定、contract 校验规则，以及 target_workspace_contract（specs/change-requests/docs/delivery/constraints 等运行时目录模型）。
- `agent-skill-matrix.yml` 与 `AGENT-SKILL-MATRIX.md` 构成 Agent↔Skill 权限矩阵的机器可读/人读双视图，agents 与 skills 两个子模块新增条目时必须同步更新该矩阵，否则 pipeline 编排器拒绝执行。
- `CLAUDE.MD` 仅转发读取顺序到 `AGENTS.md`，保证所有 AI 工具共享同一行为约束入口；`README.md` 则给出面向使用者的完整 playbook（CR 状态机、质量门、自修复闭环、各 Pipeline 节点输入/产出）。`LICENSE`、`.gitignore` 提供包级元数据。
- 三个子模块之间不存在直接代码依赖，耦合全部通过 YAML 契约与 dir-graph contract 实现：agents/_index.yml 引用 active Skill → agent-skill-matrix.yml 限定 owns/can-call/forbidden → pipeline-templates/*.pipeline.json 按 owner 选择入口并串联 Skill 节点，形成「Agent 定义 ← 权限矩阵 → Pipeline 模板」的单向装配链。
